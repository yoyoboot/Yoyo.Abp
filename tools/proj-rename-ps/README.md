# proj-rename-ps

用于将项目重命名，以及将abp主键替换为字符串

### 将gct.foundation.template迁移到gct.foundation

脚本名称： to_foundation.ps1

输入参数： 

```text
$inputRootPath = 'D:\dev\gct-jgz\ftp_none'  # 输入目录
$outputRootPath = 'D:\dev\gct-jgz\gct.foundation' # 输出目录
```

$inputRootPath = 'D:\dev\gct-jgz\gct.foundation' # 输入目录
$outputRootPath = 'D:\dev\52abp\yoyoboot' # 输出目录
